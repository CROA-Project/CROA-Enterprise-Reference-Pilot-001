First public release of CROA Enterprise Reference Pilot #001.

This author-operated reference implementation demonstrates execution-authority separation, context grounding, policy enforcement, cumulative trajectory constraints, signed Execution Change Contracts (ECCs), execution-boundary enforcement, replay protection, operation-mutation protection, and tamper-evident evidence.

The release includes eight reproducible demonstration scenarios covering legitimate execution, grounding failure, policy denial, cumulative trajectory limits, missing or forged ECCs, operation mutation, and replay attempts.

This release is a reference pilot. It is not a production-ready implementation, formal verification, or independent validation of CROA.
